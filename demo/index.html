Active Silence Local Viewer

This local-only viewer reads the derived event table, detector-boundary metadata, threshold summary, and optional local audio mappings. It is included as code only; no audio is bundled in this repository.

Optional Local Playback

Playback appears only when audio_paths.json points to local audio. The URL fragment is set to the selected event span when boundary metadata is available.

Boundary Overlay

The blue span is detected sounding time; the red span is low-energy duration. This is metadata-driven and does not redistribute audio.

Trajectory Figure

The full-corpus trajectory view is generated from the same source-condition event table.
